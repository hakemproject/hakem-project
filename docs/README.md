# MYNADI / NADI — Blueprint Project Pack

Paket ini adalah fondasi dokumentasi untuk tiga proyek yang saling berkaitan:
1. **NADI / MYNADI** — brand dan ekosistem digital.
2. **NADI Web Builder** — alat untuk membuat website, khususnya untuk UMKM.
3. **Hakem Media** — media/layanan kreatif dan konten.

Dokumen ini sengaja dibuat sebagai **blueprint kerja**, bukan klaim bahwa keputusan teknis sudah final. Bagian yang belum diputuskan diberi label `TBD` atau `PROVISIONAL` agar tidak dianggap sebagai keputusan permanen.

## Mulai dari mana
1. Baca `00_START_HERE/PROJECT_OVERVIEW.md`.
2. Baca `01_SHARED/PRODUCT_RELATIONSHIPS.md` dan `01_SHARED/DECISION_LOG.md`.
3. Baca `02_NADI/PROJECT_CONTEXT.md`, `03_WEB_BUILDER/PROJECT_CONTEXT.md`, dan `04_HAKEM_MEDIA/PROJECT_CONTEXT.md`.
4. Gunakan `01_SHARED/AI_WORKING_RULES.md` dan `01_SHARED/SESSION_HANDOFF.md` setiap kali memulai sesi AI baru.
5. Perbarui keputusan, changelog, task board, dan handoff setiap selesai sesi penting.

## Prinsip pengelolaan
- Dokumentasi adalah sumber konteks utama; jangan mengandalkan ingatan percakapan saja.
- Pisahkan fakta, keputusan, hipotesis, dan pertanyaan terbuka.
- Hindari mengunci stack sebelum kebutuhan dan risiko diaudit.
- Bangun satu fondasi bersama jika benar-benar mengurangi duplikasi, tetapi jangan membuat semua proyek saling bergantung.
- Pilih langkah terkecil yang bisa diuji oleh pengguna nyata.

## Status awal
Semua rencana dalam paket ini adalah baseline untuk ditinjau. Ganti `TBD`, asumsi, dan prioritas setelah audit serta validasi.
