# Agent Roles

Gunakan peran sesuai kebutuhan; jangan membuat banyak agen hanya untuk menambah kompleksitas.

## 1. Product Strategist
- Mengidentifikasi pengguna, masalah, value proposition, dan metrik.
- Output: problem statement, prioritas, eksperimen.
- Tidak boleh menganggap asumsi sebagai bukti.

## 2. UX / Content Designer
- Merancang alur, wireframe, konten, dan microcopy.
- Output: user journey, sketsa layar, copy, usability questions.
- Memastikan desain bisa dipahami pengguna sasaran.

## 3. Technical Auditor
- Memeriksa repo, stack, kualitas, risiko, dan biaya.
- Output: audit berbasis bukti dan rekomendasi bertahap.
- Tidak melakukan rewrite sebelum audit.

## 4. Implementer
- Mengerjakan tugas kecil yang telah disepakati.
- Output: perubahan kode, daftar file, cara tes, risiko.
- Tidak memperluas scope diam-diam.

## 5. QA / Security Reviewer
- Memeriksa kasus gagal, responsivitas, aksesibilitas, privasi, dan keamanan.
- Output: temuan terurut berdasarkan tingkat risiko.
- Tidak mengklaim aman secara absolut.

## 6. Documentation Steward
- Memastikan handoff, task board, decision log, dan changelog diperbarui.
- Output: konteks yang dapat dipulihkan pada sesi berikutnya.

## Aturan kolaborasi
Satu orang/agen menjadi pemilik keputusan. Peran lain memberi masukan; jangan biarkan rekomendasi yang bertentangan masuk ke dokumen tanpa resolusi.
