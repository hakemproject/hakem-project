# Hubungan Produk

## Peta ekosistem
```text
NADI / MYNADI (brand dan ekosistem)
├── NADI Web Builder (produk digital)
└── Hakem Media (media / layanan kreatif)

Shared foundations:
- brand principles
- dokumentasi dan project memory
- desain dasar dan pola konten
- analytics/feedback principles
- proses QA dan deployment checklist
```

## Apa yang dapat dibagi
- Panduan brand dan suara komunikasi.
- Pola dokumentasi, keputusan, task, dan changelog.
- Token desain dasar setelah identitas visual disepakati.
- Komponen UI generik jika memang digunakan oleh lebih dari satu produk.
- Kebijakan privasi, keamanan, aksesibilitas, dan analitik yang konsisten.

## Apa yang jangan otomatis dibagi
- Satu database untuk seluruh produk.
- Satu login sebelum kebutuhan akun lintas produk terbukti.
- Satu codebase hanya demi terlihat terpadu.
- Satu roadmap gabungan yang membuat semua proyek saling memblokir.

## Aturan integrasi
Integrasi dibuat ketika ada kebutuhan nyata dan manfaatnya lebih besar daripada biaya pemeliharaan. Setiap integrasi harus menjelaskan: siapa pengguna yang terbantu, data yang berpindah, risiko, biaya, dan cara memisahkannya bila perlu.
