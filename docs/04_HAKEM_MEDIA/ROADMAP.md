# Roadmap Hakem Media

## Tahap 1 — Fokus penawaran
- [ ] Pilih satu layanan utama.
- [ ] Definisikan target pelanggan.
- [ ] Tetapkan deliverable, batas revisi, dan rentang harga.
- [ ] Buat contoh portofolio yang relevan.

## Tahap 2 — Validasi penjualan
- [ ] Bicara dengan calon pelanggan.
- [ ] Tawarkan paket secara langsung.
- [ ] Catat keberatan, kebutuhan, dan kesediaan membayar.
- [ ] Revisi penawaran.

## Tahap 3 — Operasional
- [ ] Buat brief form.
- [ ] Buat template proposal dan invoice.
- [ ] Buat checklist produksi dan QA.
- [ ] Buat proses delivery dan follow-up.

## Tahap 4 — Pertumbuhan
- [ ] Dokumentasikan studi kasus dengan izin.
- [ ] Perbaiki margin dan kapasitas.
- [ ] Pertimbangkan paket berulang hanya jika kebutuhan terbukti.
