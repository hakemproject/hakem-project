# Arsitektur awal NADI

## Produk saat ini
1. NADI Home: halaman pengenalan.
2. NADI Builder: formulir + live preview + draft lokal.
3. Template Engine: akan menjadi renderer untuk halaman publik.
4. Client Sites: website lama yang harus tetap berjalan.

## Tahap berikutnya
1. Rapikan data dan validasi Builder.
2. Buat API Worker untuk membuat/membaca draft.
3. D1 sebagai sumber data profil dan situs.
4. R2 untuk gambar setelah alur upload siap.
5. Publish Worker/renderer untuk halaman publik.
6. Uji preview dan deployment sebelum mengubah URL lama.

Jangan mengklaim website sudah diterbitkan sebelum API, penyimpanan, routing, dan URL publik benar-benar aktif.
