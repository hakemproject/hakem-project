# User Journey — Web Builder

## Journey hipotesis
1. **Masuk:** pengguna memahami manfaat dan batas produk.
2. **Mulai:** memilih tipe website atau template.
3. **Isi:** memasukkan informasi usaha.
4. **Pratinjau:** melihat hasil di mobile dan desktop.
5. **Perbaiki:** mengubah teks/foto dengan petunjuk sederhana.
6. **Publikasi:** memahami URL, visibilitas, dan konsekuensi publikasi.
7. **Kelola:** kembali untuk memperbarui informasi.

## Friksi yang harus diuji
- Tidak punya foto atau copy yang siap.
- Bingung memilih template.
- Tidak memahami domain dan hosting.
- Takut salah mempublikasikan.
- Kesulitan mengedit dari ponsel.
- Tidak tahu apakah website benar-benar online.

## Eksperimen validasi
- Minta 3–5 orang dari segmen sasaran menyelesaikan prototipe.
- Jangan bantu kecuali mereka benar-benar terhenti; catat titik kebingungan.
- Ukur penyelesaian tugas dan pertanyaan yang muncul.
- Ubah prototipe sebelum menambah fitur.
