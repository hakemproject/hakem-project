# Roadmap Web Builder

## Phase 0 — Audit
- [ ] Inventaris repo, mockup, prototype, API, domain, dan hosting.
- [ ] Catat apa yang sudah berjalan dan apa yang hanya konsep.
- [ ] Tentukan batasan biaya/perangkat.

## Phase 1 — Discovery
- [ ] Pilih satu segmen UMKM.
- [ ] Wawancara calon pengguna.
- [ ] Validasi kebutuhan paling penting.
- [ ] Pilih satu job-to-be-done.

## Phase 2 — Prototype
- [ ] Wireframe onboarding sampai publikasi.
- [ ] Uji tanpa backend dengan pengguna.
- [ ] Revisi berdasarkan friksi.

## Phase 3 — MVP
- [ ] Bangun alur profil → preview → publikasi → edit.
- [ ] QA responsivitas, aksesibilitas, keamanan, dan performa.
- [ ] Tambahkan logging dan backup minimum.
- [ ] Uji dengan kelompok kecil.

## Phase 4 — Iterasi
- [ ] Evaluasi tingkat publikasi dan waktu penyelesaian.
- [ ] Tambahkan fitur hanya berdasarkan kebutuhan yang terbukti.
