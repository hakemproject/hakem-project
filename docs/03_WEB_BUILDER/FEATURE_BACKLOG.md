# Feature Backlog

## Must validate first
- [ ] Profil usaha dasar.
- [ ] Pilih template sederhana.
- [ ] Editor teks/foto yang mudah digunakan di ponsel.
- [ ] Preview.
- [ ] Publikasi dan URL yang jelas.
- [ ] Edit setelah publikasi.
- [ ] Status draft/published yang mudah dipahami.

## Kandidat fase berikutnya
- [ ] Domain custom.
- [ ] Formulir kontak atau tombol WhatsApp.
- [ ] Katalog produk/jasa.
- [ ] SEO metadata dasar.
- [ ] Analytics yang menjaga privasi.
- [ ] Multi-bahasa.
- [ ] Integrasi pembayaran.
- [ ] AI-assisted copywriting.

## Jangan bangun sebelum ada bukti
- Editor drag-and-drop sangat bebas.
- Sistem plugin kompleks.
- Marketplace besar.
- Fitur enterprise.
- Otomasi multi-step yang sulit dijelaskan.

## Format prioritas
Nilai tiap fitur menurut: masalah pengguna, frekuensi, dampak, biaya implementasi, risiko, dan bukti permintaan.
