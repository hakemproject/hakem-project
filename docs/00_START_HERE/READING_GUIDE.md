| Folder | Isi |
|---|---|
| `00_START_HERE` | Orientasi, tujuan, dan cara memakai paket |

| `02_NADI` | Konteks, visi, strategi, dan roadmap NADI/MYNADI |
| `03_WEB_BUILDER` | Konteks produk, pengguna, fitur, arsitektur sementara, dan roadmap builder |
| `04_HAKEM_MEDIA` | Konteks, penawaran layanan, alur kerja, dan roadmap media |

| `06_AI_SYSTEM` | Prompt, peran agen, format sesi, anti-amnesia |
| `07_TEMPLATES` | Templat keputusan, tugas, eksperimen, changelog, handoff |
| `08_WEBSITE_STARTERS` | Kerangka konten HTML sederhana untuk situs tiap inisiatif |

## Aturan status
- `CONFIRMED`: dinyatakan eksplisit atau telah diverifikasi.
- `PROVISIONAL`: saran awal yang perlu diuji.
- `TBD`: belum diputuskan.
- `REJECTED`: sudah ditolak; catat alasannya agar tidak berulang.

Jangan mengubah `PROVISIONAL` menjadi `CONFIRMED` hanya karena muncul berulang kali dalam percakapan.
