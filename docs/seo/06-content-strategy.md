# Content Strategy - NADI

**Status:** Aktif
**Tanggal:** 14 Oktober 2026

---

## 1. Tujuan Konten NADI

Konten NADI bukan sekadar artikel blog. Konten adalah alat untuk:
1. Edukasi - membantu UMKM memahami digitalisasi.
2. Trust - membangun kepercayaan pada NADI.
3. Akuisisi - menarik UMKM baru via search engine.
4. Retensi - membantu UMKM yang sudah bergabung.

---

## 2. Pilar Konten

### Pilar 1 - Edukasi UMKM
- Cara membuat website tanpa coding
- Manfaat website untuk UMKM
- Cara promosi online untuk warung
- Digitalisasi usaha kecil

### Pilar 2 - Studi Kasus
- UMKM yang berhasil dengan NADI
- Sebelum vs sesudah punya website
- Testimoni pemilik usaha

### Pilar 3 - Tips Praktis
- Cara menulis deskripsi produk yang menarik
- Cara memotret produk dengan HP
- Cara membuat promo yang efektif

### Pilar 4 - Berita NADI
- Update fitur NADI Builder
- Pencapaian NADI
- Kolaborasi dengan komunitas UMKM

---

## 3. Struktur Topical Cluster

Pilar Utama: Website untuk UMKM

Cluster 1: Cara membuat website
- Cara membuat website tanpa coding
- Cara membuat website gratis
- Cara membuat landing page UMKM

Cluster 2: Manfaat website untuk UMKM
- Kenapa UMKM butuh website
- Website vs media sosial
- Website untuk warung makan

Cluster 3: Tips digitalisasi UMKM
- Cara memotret produk dengan HP
- Cara menulis deskripsi produk
- Cara promosi via WhatsApp

---

## 4. Internal Linking

Aturan:
1. Setiap artikel harus link ke minimal 2 artikel lain di cluster yang sama.
2. Setiap artikel harus link ke halaman NADI Builder.
3. Halaman NADI Node harus link ke NADI Home dan Builder.

---

## 5. Frekuensi & Format

| Fase | Frekuensi | Format |
|:---|:---|:---|
| Fase 1 | 1 artikel/bulan | Panduan lengkap |
| Fase 2 | 2 artikel/bulan | Panduan + studi kasus |
| Fase 3 | 4 artikel/bulan | Panduan + studi kasus + tips + berita |

---

## 6. Tone of Voice

- Sederhana - hindari jargon teknis.
- Ramah - seperti teman yang membantu.
- Praktis - langsung bisa dipraktikkan.
- Optimis - bangun semangat UMKM.

---

## 7. Aturan Konten

1. Jangan mengarang data atau statistik.
2. Selalu sertakan sumber jika mengutip data.
3. Selalu optimalkan untuk 1 keyword utama per artikel.
4. Selalu gunakan gambar orisinal.
5. Selalu review sebelum publish.
