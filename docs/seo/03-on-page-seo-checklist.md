# On-Page SEO Checklist - NADI

**Status:** Aktif
**Tanggal:** 14 Oktober 2026

---

## Cara Pakai

Gunakan checklist ini untuk setiap halaman yang akan
dipublikasikan di ekosistem NADI. Tidak ada halaman yang boleh
dipublikasikan jika belum melewati checklist ini.

---

## A. Metadata Dasar

- [ ] Title tag - unik, 50-60 karakter, mengandung keyword utama.
  Contoh: Bakso Pak Joko - Bakso Sapi Rumahan di Surabaya
- [ ] Meta description - unik, 150-160 karakter, mengandung CTA.
- [ ] Canonical URL - mengarah ke URL utama.
- [ ] Language attribute - html lang=id
- [ ] Viewport meta

---

## B. Struktur Heading

- [ ] H1 - hanya satu per halaman, mengandung keyword utama.
- [ ] H2 - untuk section utama.
- [ ] H3 - untuk sub-section jika perlu.
- [ ] Urutan heading logis - tidak ada lompatan.

---

## C. Konten

- [ ] Konten unik - tidak duplikat.
- [ ] Kata kunci natural - tidak keyword stuffing.
- [ ] Konten minimal 300 kata untuk halaman utama.
- [ ] Informasi lengkap: nama, kategori, deskripsi, promo, alamat, WA, sosmed.

---

## D. Gambar

- [ ] Format WebP
- [ ] Alt text - deskriptif, mengandung keyword.
- [ ] Ukuran: owner max 100 KB, usaha max 120 KB, produk max 120 KB
- [ ] Lazy loading untuk gambar di bawah fold.
- [ ] Dimensi eksplisit (width & height) untuk mencegah CLS.

---

## E. Link

- [ ] Internal link - tautan ke halaman lain di ekosistem NADI.
- [ ] External link - tautan ke sosial media UMKM.
- [ ] WhatsApp link - https://wa.me/62xxx?text=Halo
- [ ] Maps link - https://maps.google.com/?q=lat,lng
- [ ] Semua link valid - tidak ada 404.

---

## F. Structured Data (JSON-LD)

- [ ] LocalBusiness untuk setiap NADI Node.
- [ ] Organization untuk NADI Home.
- [ ] WebSite dengan SearchAction untuk Builder.
- [ ] BreadcrumbList untuk navigasi.
- [ ] Validasi di Rich Results Test.

---

## G. Social Meta

- [ ] Open Graph - og:title, og:description, og:image, og:url
- [ ] Twitter Card - twitter:card, twitter:title, twitter:description
- [ ] Og:image - 1200x630px, max 200KB.

---

## H. Performa

- [ ] LCP maks 2,5 detik.
- [ ] INP maks 200 ms.
- [ ] CLS maks 0,1.
- [ ] Total transfer awal maks 500 KB.
- [ ] Tidak ada library JS berat.
- [ ] Tidak ada autoplay video.
- [ ] Tidak ada carousel otomatis.
- [ ] Font sistem atau self-hosted.

---

## I. Mobile-Friendly

- [ ] Responsif di 320px, 375px, 414px, 768px, 1024px+.
- [ ] Tombol mudah dijangkau dengan jempol.
- [ ] Teks mudah dibaca minimal 16px.
- [ ] WhatsApp button sticky.
- [ ] Tidak ada horizontal scroll.

---

## J. Aksesibilitas

- [ ] Kontras warna memenuhi WCAG AA.
- [ ] Alt text di semua gambar.
- [ ] Label untuk form input.
- [ ] Fokus keyboard terlihat.
- [ ] ARIA jika perlu.
