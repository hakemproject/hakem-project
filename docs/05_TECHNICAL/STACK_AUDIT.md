# Stack Audit

## Status
Belum ada stack final yang dapat dianggap sebagai keputusan berdasarkan blueprint ini.

## Inventaris yang perlu dikumpulkan
- Repository dan branch aktif.
- Bahasa, framework, versi runtime, dan package manager.
- Database, schema, migrasi, dan backup.
- Hosting, domain, DNS, dan pipeline deploy.
- Layanan pihak ketiga dan kredensial (jangan menaruh secret di dokumen ini).
- Tes otomatis, linting, dan build status.
- Bug terbuka dan technical debt.
- Biaya bulanan dan batas penggunaan.

## Kriteria evaluasi
- Kesesuaian kebutuhan.
- Kemampuan pemilik untuk memelihara.
- Dokumentasi dan ekosistem.
- Biaya dan batas gratis.
- Deployment dan rollback.
- Keamanan, backup, dan portabilitas.
- Dukungan mobile/performa.
- Risiko vendor lock-in.

## Output audit
Buat tabel:
`Area | Kondisi sekarang | Bukti | Risiko | Rekomendasi | Keputusan | Pemilik`.

Jangan memilih stack hanya karena sedang populer atau karena model AI lebih familier dengannya.
