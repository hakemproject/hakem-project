# Roadmap NADI / MYNADI

## Tahap 1 — Kejelasan identitas
- [ ] Putuskan peran NADI dan MYNADI dalam brand architecture.
- [ ] Audit domain, handle sosial, dan risiko nama.
- [ ] Tulis satu kalimat positioning.
- [ ] Tentukan CTA utama.

## Tahap 2 — Landing page
- [ ] Susun konten hero, manfaat, ekosistem, dan kontak.
- [ ] Uji pada perangkat mobile.
- [ ] Uji pemahaman pesan dengan beberapa calon pengguna.
- [ ] Perbaiki copy berdasarkan kebingungan nyata.

## Tahap 3 — Sistem brand minimum
- [ ] Logo/wordmark final.
- [ ] Warna, tipografi, jarak, dan komponen dasar.
- [ ] Aturan penggunaan nama produk di bawah NADI.
- [ ] Template sosial dan dokumen.

## Kriteria selesai awal
Seseorang yang baru mengenal NADI dapat menjelaskan apa itu, siapa yang dibantu, dan tindakan apa yang bisa dilakukan berikutnya.
