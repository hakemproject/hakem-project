# NADI / MYNADI — Project Context

## Identitas
- **Nama inti:** NADI.
- **Nama ekosistem/alamat digital:** MYNADI (provisional framing).
- **Status:** perencanaan; validasi identitas, domain, dan penggunaan publik masih perlu dilakukan.
- **Latar nama:** NADI diinginkan sebagai nama utama; ketika alamat `nadi.pages.dev` tidak tersedia, MYNADI menjadi solusi penamaan untuk alamat digital/ekosistem. `nadi.my.id` pernah disebut tersedia dan cocok untuk konteks Indonesia; verifikasi ulang sebelum pembelian/peluncuran.

## Tujuan
Membangun identitas digital yang konsisten dan dapat menaungi produk atau layanan terkait tanpa membingungkan pengguna.
